# Installation

## From crates.io

```bash
cargo install tempurview
```

This installs two binaries: `tempurview` and `tpv` (short alias).

## From source

```bash
git clone https://github.com/Tatch-AI/tempurview.git
cd tempurview
cargo install --path .
```

## Verify

```bash
tpv --version
tpv test-connection
```
